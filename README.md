### Spenzer: Autonomous Eldercare Companion Robot
Prototype built on a **Raspberry Pi 3 and an ESP32-S3**.
- A **YOLO-Tiny** object-detection model in the pill dispenser helps make sure elderly users take the pills they are supposed to take.
- The Raspberry Pi handles vision, and the ESP32-S3 handles motor and hardware control.

- Stack: Python, Gemini, Google Vertex AI, RAG.
